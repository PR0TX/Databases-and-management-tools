# Лабораторна робота №1(Система обліку екзаменаційних балів студентів)

Мета — розробка, нормалізація та реалізація схеми БД у PostgreSQL з використанням інструментарію **pgAdmin 4**.

---

## 🗂 Структура БД
- **Student** — студенти (ПІБ, email, навчальна група).  
- **Instructor** — викладачі (ПІБ, email, кафедра).  
- **Course** — курси (назва, кредити, семестр, викладач).  
- **Enrollment** — асоціативна таблиця (студент ↔ курс) з атрибутами оцінювання.

Використано:
- `PK` (первинні ключі, в т.ч. складовий у `Enrollment`);  
- `FK` (зовнішні ключі з каскадними діями);  
- `NOT NULL`, `UNIQUE`, `CHECK` обмеження.

---

## ⚙️ Технології
- **PostgreSQL 17**  
- **pgAdmin 4**  
- ER-діаграма в нотації **Crow’s Foot**
